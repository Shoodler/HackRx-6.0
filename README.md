# HackRx 6.0 - RAG API

[![Ask DeepWiki](https://devin.ai/assets/askdeepwiki.png)](https://deepwiki.com/Shoodler/HackRx-6.0)

This repository contains a Retrieval-Augmented Generation (RAG) API built with FastAPI for the HackRx 6.0 competition. The API takes a document URL (PDF or DOCX) and a list of questions, then returns answers generated by an LLM based on the content of the document.

## Features

-   **FastAPI Backend**: A robust and fast web server for handling API requests.
-   **Document Processing**: Downloads and extracts text from `.pdf` and `.docx` files hosted at a given URL.
-   **Semantic Search**: Uses `sentence-transformers` (`all-MiniLM-L6-v2`) to create vector embeddings for text chunks.
-   **Efficient Retrieval**: Implements a `faiss-cpu` vector index for fast and accurate retrieval of relevant document context.
-   **LLM Integration**: Leverages the Groq API for extremely fast inference with the `llama-3.1-8b-instant` model to generate answers.
-   **RAG Pipeline**: Implements a full RAG pipeline: document chunking, embedding, retrieval, and generation.

## How It Works

The API follows a standard Retrieval-Augmented Generation pattern to answer questions about a document.

1.  **Request Handling**: The `main.py` FastAPI application receives a POST request at the `/hackrx/run` endpoint. The request includes a document URL and a list of questions.
2.  **Document Ingestion**: The `Retriever` class is initialized from the URL.
    -   `utils/document_parser.py`: The document is downloaded. Text is extracted using `PyMuPDF` for PDFs or `python-docx` for DOCX files.
3.  **Chunking & Embedding**:
    -   The extracted text is split into smaller, overlapping chunks of text to ensure context is preserved.
    -   The `sentence-transformers` model embeds each chunk into a high-dimensional vector.
4.  **Vector Indexing**:
    -   A `faiss` index is built from the document's chunk embeddings. This index allows for very fast semantic similarity searches. To use cosine similarity, vectors are L2 normalized and an `IndexFlatIP` (Inner Product) index is used.
5.  **Retrieval**:
    -   For each question in the request, the question is embedded into a vector.
    -   The `faiss` index is queried with the question vector to retrieve the `top_k` most semantically similar text chunks from the document.
6.  **Generation**:
    -   `utils/llm.py`: The retrieved text chunks are compiled into a context.
    -   A prompt is constructed that instructs the LLM (Groq's Llama 3.1) to answer the user's question based *only* on the provided context.
    -   The Groq API is queried, and it returns a generated answer.
7.  **Response**: The answers for all questions are collected and returned as a JSON array.

## Setup and Installation

### Prerequisites

-   Python 3.8+
-   A Groq API Key

### Instructions

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/shoodler/hackrx-6.0.git
    cd hackrx-6.0
    ```

2.  **Create a virtual environment (recommended):**
    ```bash
    python -m venv venv
    source venv/bin/activate  # On Windows, use `venv\Scripts\activate`
    ```

3.  **Install the dependencies:**
    ```bash
    pip install -r requirements.txt
    ```

4.  **Set up your environment variables:**
    Create a file named `.env` in the root of the project and add your Groq API key:
    ```
    GROQ_API_KEY="your_groq_api_key_here"
    ```

## Usage

1.  **Run the API server:**
    Use `uvicorn` to start the web server from the project root.
    ```bash
    uvicorn main:app --reload
    ```
    The API will be available at `http://127.0.0.1:8000`.

2.  **Send a request:**
    You can use `curl` or any API client to send a POST request to the `/hackrx/run` endpoint.

    **Example `curl` command:**
    ```bash
    curl -X 'POST' \
      'http://127.0.0.1:8000/hackrx/run' \
      -H 'accept: application/json' \
      -H 'Content-Type: application/json' \
      -d '{
      "documents": "https://www.africau.edu/images/default/sample.pdf",
      "questions": [
        "What is a PDF file?",
        "What is the capital of France?"
      ]
    }'
    ```

    **Input JSON Format:**
    -   `documents`: A string containing the URL to the `.pdf` or `.docx` file.
    -   `questions`: A list of strings, where each string is a question about the document.

    **Output JSON Format:**
    The API returns a list of objects, each containing the original question and the generated answer.
    ```json
    [
      {
        "question": "What is a PDF file?",
        "answer": "A PDF file is a Portable Document Format file, developed by Adobe Systems. It can describe documents containing text, graphics, and images in a device-independent and resolution-independent format."
      },
      {
        "question": "What is the capital of France?",
        "answer": "No relevant context found in the document."
      }
    ]
    ```
